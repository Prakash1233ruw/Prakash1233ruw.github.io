Microservices · 5 services

Real-Time Quiz Application

  • Five independent services built with Java and Spring Boot: Quiz, Question, User, API Gateway and Eureka Service Registry.
  • Netflix Eureka handles service discovery. Each service registers and finds its peers at runtime, so there are no hardcoded URLs and each can deploy on its own.
  • The User Service is secured with BCrypt password hashing. Services talk to each other through Spring RestTemplate.
  • React.js pages for login, quiz selection, taking the quiz and viewing results, connected to the Spring Boot REST APIs.
